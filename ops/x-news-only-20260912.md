# X character-post allocation retired at the owner's request

Scope: BUZZ NOW's X feed only. On 2026-09-12 the owner requested that the two low-reach AI-photo/one-liner character turns be reassigned to the ordinary 'why is this trending?' article posts.

X now selects trend on every turn and rejects character reservations and legacy/direct character sends. All ten existing Japan-time windows remain, including 12:30 and 21:00. The reclaimed fifth/tenth accepted-post turns are reserved for original normal news rather than quotes. Other quote behavior is unchanged. The existing daily cap, minimum interval, per-keyword cooldown, quality filters, uncertain-send block and no-catch-up behavior remain. No eligible story means skip, not a filler character post.

Threads retains its separate 8:2 rotation, approved image/captions and original 14-day trial. Trial start dates and historical accepted counts are not reset. No existing public post, profile, image, advertisement, analytics collection, other site's feed, account or budget is deleted or changed. No manual posts are used for tests.

Status mix_policy v3 reports per-platform limits, with legacy top-level counts explicitly scoped to X. A production GET-only check must confirm X 10/0, Threads 8/2 and active normal posting before this change is reported as live. Configuration completion is not evidence that a new public post has appeared. Autonomous analytics/improvement remains on hold; no new timed ChatGPT task or API budget is enabled.
